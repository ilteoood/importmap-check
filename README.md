# esm-check-updates

Dependency checker/updater for ESM dependencies from common CDNs.

## Overview

ECU reads your ESM importmap and identifies dependency versions and available upgrades. It can optionally update your importmaps.

Features:

- Modern CDN support: [jsDelivr](https://www.jsdelivr.com/esm), [esm.sh](https://esm.sh/)
- Simple, no-dep CLI.
